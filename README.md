# Sistema informatizado: R1

## Descrição

Este projeto é um sistema Java desenvolvido para automatizar rotinas de uma casa de leilões. O objetivo é facilitar o gerenciamento de leilões, permitindo o cadastro de produtos, registro de lances e controle de informações relacionadas aos participantes e aos eventos de leilão.

## Tecnologias utilizadas

- **Java** – utilizado para implementar a lógica de negócios e as interfaces do sistema.
- **MySQL** – empregado como SGBD para armazenar dados dos produtos, leilões e lances.

O repositório está versionado com Git e hospedado no GitHub para permitir controle de versão, colaboração entre os desenvolvedores e histórico de desenvolvimento.
